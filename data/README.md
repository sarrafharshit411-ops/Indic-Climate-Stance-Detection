# Dataset directory

The project uses a supplied English stance dataset translated into Hindi and Bengali with AI4Bharat IndicTrans2.

Expected processed files: `hindi_train.csv`, `hindi_val.csv`, `hindi_test.csv`, `bengali_train.csv`, `bengali_val.csv`, `bengali_test.csv`.

The exact upstream dataset source and redistribution licence have not yet been independently verified. Do not publish source or translated CSVs until those terms are confirmed. See [dataset protocol](../docs/DATASET_AND_PROTOCOL.md).
