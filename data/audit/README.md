# Structural audit artifacts

This directory stores compact audit summaries for the supplied translated dataset files.

The six CSV split files were checked for expected row counts and schema, missing values, empty text, duplicate IDs, duplicate complete rows, label values, split values, and cross-language alignment. No rows were removed and no labels or translations were changed by the structural-cleaning step.

Translation quality has not been fully validated. The data itself is intentionally not included in this repository while source provenance and redistribution rights remain unverified.

Label map: 0=Against, 1=Favour, 2=None.
