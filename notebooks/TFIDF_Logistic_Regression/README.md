# TF-IDF + Logistic Regression

Traditional machine learning baseline for Indic Climate Stance Detection.

## Methodology
- Word-level TF-IDF
- Unigrams and bigrams (1–2)
- Logistic Regression
- Separate Hindi and Bengali models
- Validation and test evaluation

## Evaluation Metrics
- Accuracy
- Macro F1-score
- Weighted F1-score
- Classification Report
- Confusion Matrix
